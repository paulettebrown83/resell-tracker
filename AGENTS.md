# Repository instructions

Read CLAUDE.md for this repository’s architecture, verification requirements and privacy rules.

## Standing rule: clean up after yourself

Paulette requires every agent to clean up its own work environment. Track the pages, tabs, panels, files, processes, servers, temporary environments, downloads and generated artifacts you create. Close your own pages, tabs, panels and open file handles when finished; stop your own processes and servers; remove disposable temporary files, caches and duplicate downloads after verifying the retained deliverable. Do this as part of completing the task, without waiting for a reminder.

Preserve Paulette’s pre-existing tabs, apps, files, running work and final deliverables. Verify ownership before closing, killing or deleting anything; do not use broad cleanup commands. Keep a still-needed resource only while work actively depends on it, then clean it up. Carry this rule and any outstanding resource ownership into every agent/task handoff. Include this rule in every new or updated AGENTS.md. If something cannot be closed safely or access is blocked, report the exact remaining resource and reason instead of claiming cleanup is complete.
